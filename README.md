# 等速肌力综合报告生成器

从固定结构 Excel 读取运动员信息、等速峰力矩和 Sheet 3 标准，重新计算肌群比例及双侧差异，并生成 1600×2000 PNG 和同版 PDF。

支持 1–10 个关节：每页最多展示 5 个关节；6–10 个关节自动生成两张 PNG，并合并为一个多页 PDF，避免为塞入一页而压缩文字。

程序严格遵守数据边界：

- Sheet 1 只读取个人信息。
- Sheet 2 是唯一测试数值来源。
- Sheet 3 是仪表盘区间、状态颜色和重点标签的配置来源。
- 底部“关键薄弱环节”按程序内固定的关节比例范围与 `>0.10` 双侧差异规则汇总，不读取 Sheet 4 结论。
- Sheet 4 只作为人工结论存档，不参与数值或状态判定。
- 原始 Excel 不会被修改。
- Sheet 3 配置不完整时不使用默认医学或运动科学标准，并生成明确标注的中性“预览版”；`--validate-only` 仍会返回配置错误。

## 安装与运行

```powershell
python -m pip install -r requirements.txt
python run_report.py
python main.py "输入文件.xlsx" --validate-only
python main.py "输入文件.xlsx" --output-dir output
```

最简单的方式是在项目目录运行 `python run_report.py`。它会优先从 `D:\博士\江苏体科所\等速测试新报告_用于测试\运行文件夹` 调取 `.xlsx`，再检查项目目录和 Downloads；报告统一输出到项目的 `output` 目录。也可以把 Excel 路径拖到脚本命令后：

```powershell
python run_report.py "C:\路径\输入文件.xlsx"
```

默认同时输出 PNG 和 PDF；使用 `--no-pdf` 可只输出 PNG。

## Sheet 3 最终结构

四张配置表可以放在 `3_绘图配置` 的不同区域。程序按表头定位，不依赖固定行号。

### 1. 比例仪表盘配置

`显示顺序｜关节｜仪表最小值｜低侧红区上界｜低侧橙区上界｜目标下限｜目标上限｜高侧黄区上界｜高侧橙区上界｜仪表最大值｜标准来源/状态｜启用｜备注`

边界必须严格递增。颜色区间为：

- `[仪表最小值, 低侧红区上界)`：红色
- `[低侧红区上界, 低侧橙区上界)`：橙色
- `[低侧橙区上界, 目标下限)`：黄色
- `[目标下限, 目标上限]`：绿色
- `(目标上限, 高侧黄区上界]`：黄色
- `(高侧黄区上界, 高侧橙区上界]`：橙色
- `(高侧橙区上界, 仪表最大值]`：红色

### 2. 双侧差异配置

`判定顺序｜状态｜最小值_含｜最大值_不含｜符号｜颜色HEX｜启用｜说明`

最后一级的 `最大值_不含` 留空表示没有上限。

### 3. 重点/关注规则

`规则组｜规则顺序｜输出标签｜指标｜比较符｜阈值｜组内关系｜标签颜色HEX｜启用｜说明`

支持指标：

- 比值红色项数
- 比值偏离项数
- 双侧差异↑项数
- 双侧差异！或↑项数
- 快速异常项数
- 同速双侧比值异常次数
- 总异常项数

同一规则组使用“任一”或“全部”组合，按规则顺序返回第一个匹配标签。

### 4. 颜色配置

`用途｜颜色HEX｜说明`

必须包含：`主色、边框色、目标范围、轻度偏离、中度偏离、明显偏离、缺失、重点、关注`。
